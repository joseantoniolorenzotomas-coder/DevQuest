# Constitución del Proyecto — Principios Innegociables

1. **Simplicidad del Stack**: Priorizar código sencillo y mantenible sin frameworks innecesarios.
2. **La Spec Manda**: Ninguna funcionalidad se implementa si no está descrita y aprobada en su `spec.md`.
3. **Separación de Capas**: Mantener separada la lógica de negocio (funciones puras) de la interfaz de usuario.
4. **Política de Tests (TDD)**: Toda función crítica debe contar con pruebas unitarias (`node --test`) creadas antes o durante el código.
5. **Protección de Datos y Seguridad**: Nunca exponer credenciales ni almacenar datos sin cifrar/sanitizar.
6. **Idioma**: La documentación, las especificaciones y la interfaz deben estar en Español.
